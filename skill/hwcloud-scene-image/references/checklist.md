# 交付前自检 · v2

渲染完 PNG 后**必须打开图逐条核对**。第 -1 条由脚本判定，第 0 条是硬门槛。经验上第一版会有 2–4 条不通过，迭代 2–3 轮才达标。

## 第 -1 条（机器判，不用眼看）：连线全部接上

```bash
python scripts/linklint.py <scene.html>
```

退出码必须是 0。它逐个检查每根线的两端是否贴住元素边缘或接上另一根线；
不通过时会直接告诉你「第几条线的哪一端，在什么坐标，差了多远」。

`render.py` 已经自动跑这一步（退出码 3 = 有断线），**但有断线时它仍然会输出 PNG**，
所以看到 PNG 生成了不代表通过了。

这一步不能靠眼睛替代：一段 800px 的缺失横线，在 1760 原图上看着完全正常，
缩到 240px 更是彻底消失——它只在几何上存在，不在视觉上存在。

## 第 0 条（硬门槛）：缩略可读

```bash
python scripts/preview.py out.png --width 240
```

打开生成的 `*_preview.png`，问三个问题：

1. 标题读得出来吗？
2. 每一个标签，能看出「大意」吗（不必逐字，但要像词不像斑）？
3. 一眼能指出"哪一块是重点"吗？

**三条里任何一条答"否"，就不要往下看了，回去减元素、放大字号。** 这一条不过，图在网页里就是废的。

## v3 专用（图形化版式，只用 D / E 时看这节）

1. **内容区没有整块白卡**。图形直接落在淡蓝面板上，白底只出现在徽章、浮标这类小件上。
2. **图标 ≥ 84px**，视觉线宽 7–9px（= `stroke × 显示尺寸 / 24`）。按 56px 画的图标在 v3 里一定糊。
3. **标签 ≤ 4 处**，每处 2–3 字。超过 4 处就说明还在用文字讲事情，回去把信息画成图形。
4. **边界靠阴影，不靠描边**。圆和方块默认无边框；加 3px 硬边会立刻退回 v2 的"框框感"。
5. **点阵 / 柔光 opacity ≤ .45**，低于这个值看着脏，高于 .5 缩略后是灰色噪点。
6. **渐变体全图唯一**，且落在读者第一眼要看的那一个上（核心 / 中间步骤）。
7. **连线不压图形**。竖总线要绕开标签（D 版式里 `x=610 > 标签右缘 565` 就是为这个）。

## 结构

1. **三层都在**：外壳白卡 → 淡蓝面板 → 内容白卡，边缘都露得出来。
2. **底部有蓝带**：内容卡下缘（884）到面板下缘（1004）留 120px 蓝，没有白色断层。
3. **浮标破框**：右缘 1632，越过面板 32px，投影明显重于其他卡片，且**没有压住内容元素**（内容右缘 ≤1230）。

## 密度

4. **内容区元素 ≤ 7 个**（连线、手柄不算）。数一遍，超了就删。
5. **没有装饰性骨架条**。层名/节点名/输出类型都是真实短标签（2–4 字）。

## 色彩

6. **只有蓝紫 + 灰白**，没有绿/橙/黄/粉；若有暖色只能是 `#F58A8A` 且仅表告警。
7. **渐变瓦片全图恰好 1 个**，位于视觉中心，白色图标清晰。

## 图形

8. **连线无悬空**（由第 -1 条机器判定）；再看箭头是不是等腰三角、是否正对目标元素中线。
   分叉是否读得出「一个枢纽分出三路」，而不是两条互不相连的横线。
9. **元素不重叠、不被裁**；三张并排卡片的 left 等距、中心正对箭头。
10. **选中手柄**中心对准节点角点（`left = 角点 x − 10`），不浮在角外。
11. **气泡虚线可见**（没被选中光晕盖住）；需要时给连线 svg 加 `z-index:6`。

## 文字

12. **字号都 ≥40px**；标题 76px 单行放得下；浮标 4 个字不折行。

## 气质（主观但重要）

- 缩到 50% 看：结构还成立吗？
- 眯眼看：第一落点是那张渐变瓦片吗？
- 遮住文字看：像不像一页企业级 SaaS 技术说明书？像海报/像插画/像 PPT 模板就说明装饰多了。

## 不通过的典型后果

| 没通过 | 观感 |
|---|---|
| 第 0 条 | 网页卡片里糊成一片浅灰，等于没配图（最常见返工原因） |
| 第 4 条 | 元素一多，缩略后变噪点，重点丢失 |
| 第 5 条 | 细骨架条缩略后是灰斑，看着像渲染失败 |
| 第 2 条 | 蓝色面板看着像个边框，整张图发闷 |
| 第 -1 条 | 线断在半路，读者以为渲染坏了；这种错误肉眼最难发现、也最伤可信度 |
| 第 8/10 条 | 显得粗糙、不可信 |
| 第 9 条 | 像渲染 bug |
