# 风格 Token 表 · v2

所有值都来自对 14 张原始场景图（660×420 / 1760×1120 / 878×562 三种尺寸）的实测取样，并按「缩到 240px 仍可读」重新定标。

**改内容可以，改 token 不行**——一旦偏离，整张图就不属于这个风格族。

> **v1 → v2 改了什么**：字号 20px → 48px、渐变瓦片 132 → 170–200、节点 268×88 → 330×132、元素上限 25 个 → 7 个、骨架条改为真实短标签、描边 1px → 3–5px、连线 2px → 4px。
> 原因：v1 按 1760px 观看设计，但实际观看宽度是 240px（1/7.3 缩放），20px 的字缩完只剩 2.7px。

### 配色纪律

- 色相锁死 **200°–250°**，不允许绿、橙、黄、粉混入（告警色是唯一例外）。
- 饱和度只投放约 **20% 面积**：渐变瓦片、选中描边。其余是高明度低饱和的蓝白。
- **每个节点里最多 1 个蓝色元素**。禁止多彩图标、禁止每个卡片一种颜色。
- 告警色面积 ≤ 0.5%。

## 3. 投影（三级层高，色永远是深蓝，不是黑）

| 级 | 用途 | 值 |
|---|---|---|
| 1 | 小控件 | `0 4px 12px rgba(31,71,141,.045)` |
| 2 | 节点 / 层条 | `0 8px 22px rgba(31,71,141,.06)` |
| 3 | 外壳白卡 | `0 22px 60px rgba(31,71,141,.085), 0 4px 14px rgba(31,71,141,.04)` |
| 4 | 浮标（最重） | `0 20px 48px rgba(31,71,141,.16), 0 3px 8px rgba(31,71,141,.06)` |
| 特 | 渐变瓦片 | `0 20px 44px rgba(74,157,252,.42), 0 0 48px 10px rgba(124,107,245,.16)` |
| 特 | 选中节点 | `0 0 0 12px rgba(74,157,252,.11), 0 18px 40px rgba(74,157,252,.20)` |

**不要**用黑色阴影（会显脏）、不要方向性光源、不要高光、不要 AO、不要体积光、不要玻璃/金属/纹理。全部哑光平涂。

## 4. 字体

```css
font-family:"Microsoft YaHei","PingFang SC","Source Han Sans SC",sans-serif;
-webkit-font-smoothing:antialiased;
```

| 层级 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 主标题 | 76px | 600 | `#191919` |
| 层名 / 节点标签 | 48–50px | 500 | `#191919` |
| 输入条例句 | 46–48px | 400 | `#5A616B` |
| 浮标 | 44px | 500 | `#191919` |
| 气泡 | 44px | 500 | `#4A9DFC` |

英文与技术名词（`API`、`MCP`、`Python`）同字号无衬线混排，**不换字体、不加粗**。除气泡外，所有文字都是黑或灰。

**字号下限 40px，没有例外。** 20px 的字在 240px 缩略里只有 2.7px 高，等于噪点。

## 5. 图标

- 统一**蓝色单色线性**（`#4A9DFC`），`stroke-width 2.2`，`linecap/linejoin: round`，不填充。
- 尺寸：瓦片内 `84–100`；浮标 `46`；节点内 `50–54`。
- 线宽不能低于 2，否则缩略后图标消失。
- 常用语义：节点/拓扑、分层、数据库、文档、闪电（异步）、铅笔（编辑）、齿轮、云、盾牌、代码。

## 6. 文字 vs 骨架条

**优先用真实短标签（2–4 个汉字），不要用骨架条模拟文字。**

| 场景 | 用什么 | 原因 |
|---|---|---|
| 层名、节点名、输出类型 | 真实文字 48px | 缩略后仍能辨认字形 |
| 需要表达"还有更多内容" | 最多 1 条骨架条，`h 20 / r10 / #D9E7FA` | 骨架条是装饰，不是信息 |
| 说明性长文本 | 不写 | 一图一件事，不塞段落 |

v1 那种"每个节点两三条 12px 细骨架条"，在 240px 缩放下就是几块灰斑，纯属噪音。

## 8. v3 图形化 token（圆 + 图标驱动）

v3 的取向：**图形是主体，文字是注脚**。尺寸仍是 1760×1120，但内容区不再有整块白卡。

| 项 | v2 | v3 |
|---|---|---|
| 内容区底 | 1310×644 白色 content 卡 | **无**，图形直接浮在淡蓝面板上 |
| 主体形状 | 圆角矩形节点 r32–36 | 圆 / 圆角方块 r44–64 |
| 图标呈现 | 46–54px / stroke 2.2 | 84–190px / stroke 1.3–2.0 |
| 文字量 | 每元素 2–4 字，5–7 处 | 每元素 2–3 字，**3–4 处** + 浮标 |
| 边界 | 3px 描边 | **阴影优先**，能不用描边就不用 |

### 图标线宽换算（重要）

24 网格的 symbol，显示尺寸 S 时的视觉线宽 = `stroke × S / 24`。目标是 **视觉线宽 7–9px**——缩到 240px 时约 1px，刚好还看得见。

| 显示尺寸 | 用 stroke |
|---|---|
| 84–108 | 1.9–2.0 |
| 130–140 | 1.5 |
| 170–190 | 1.3 |

`assets/icons.svg` 里的 symbol **故意不写 stroke-width**，就是留给使用处按尺寸配比。写死会让同一枚图标在 84px 和 190px 下粗细失控。
