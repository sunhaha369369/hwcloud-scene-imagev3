# 产品场景图 · 图形化风格规范（可执行版）

> 用途：后续只给「图片标题」时，按本文件直接生成风格一致的场景图。
> 分析样本：4 个产品线共 14 张原始场景图（`samples/` 本地保留，因版权未随仓库分发）。
> 可视化版本：`docs/style-guide.html`　·　可执行模板：`skill/hwcloud-scene-image/`

---

## 0. 一句话定性

**扁平矢量图形系统**（flat vector graphic illustration）：图形直接落在淡蓝面板上、大图标与图形装置承载语义、渐变和投影负责分层、少数几根连线表达关系。**无人物、无透视、无照片质感。**

三条原则，按重要性排序：

1. **不铺内容白卡** —— 图形直接落地，边界靠阴影不靠描边。这是"去框框感"的关键。
2. **图形要大** —— 图标 84–190px，核心装置占画布 50–55%。小图形等于装饰。
3. **文字退为注脚** —— 全图 ≤4 处，每处 2–3 字。省下的信息量交给形状。

---

## 2. 构图：两层壳 + 图形落地

层与层**逐层向右下偏移**，这是全系统唯一的"深度"来源。

| 层 | 内容 | 关键参数 |
|---|---|---|
| L0 | 画布 | `#FFFFFF`，无边框 |
| L1 | 外壳白卡 | `110,66` 起，`1520×968`，圆角 62，投影 `0 22 60 rgba(31,71,141,.085)` |
| L2 | 淡蓝面板 | `140,96` 起，`1460×908`，圆角 50，四段渐变止于 `#F5FAFF` |
| L3 | **图形层** | 直接落在 L2 上，**不铺白卡**；圆、叠页、徽章、箭头按版式摆放 |
| L4 | 破框浮标 | `left 1312`，`320×128`，圆角 32，越过卡片右缘，投影最重 |

**两条纪律**

1. **L3 不是白卡。** 一旦铺上整块白色内容区，画面立刻变成"框里装东西"，缩略后是一块发灰的方块。
2. **边界靠阴影，不靠描边。** 除白圆徽章的 3px `#CFE0F4` 淡蓝描边外，其余元素一律无边框。

**标题位**：`190,132`，76px / 600。

## 4. 光影 / 材质 / 视角

**光影**
- 无方向性主光源；无投影锥、无高光、无 AO、无体积光
- 只有两级层高投影：白卡 `0 22 60` / 浮标 `0 20 48`
- 投影色为**深蓝 `rgba(31,71,141,…)` 而非黑**
- 渐变核心体带同色柔光晕：`0 0 64px 12px rgba(124,107,245,.16)`

**材质**
- 全哑光：无金属、无玻璃、无反射、无纹理
- 唯一"实体感" = **渐变核心体**（135° 三段 + 柔光 + 内高光 3px 白 26%）
- 白圆徽章：纯白 + 3px 淡蓝描边 + 投影
- 其余元素无描边，靠投影分离

**视角**
- **严格正交正视 0° 透视**；矩形轴对齐，圆保持正圆
- 无等距 3D、无倾斜、无地平线、无场景背景

## 5. 氛围

洁净 · 克制 · 可信 · 轻科技 —— **企业级 SaaS 技术说明书气质**。靠结构与留白建立秩序，不靠色彩特效制造情绪。讲"怎么运作"而非"多酷"。无人、无表情、无戏剧性，可无限复用不疲劳。

信息密度：中低，一图一件事。

### 线宽换算

```
视觉线宽 = stroke-width × 显示尺寸 / 24
```

| 显示尺寸 | stroke | 视觉线宽 | 典型位置 |
|---|---|---|---|
| 52px | 1.8 | ≈3.9px | 浮标内小图标 |
| 108px | 2.0 | ≈9.0px | D 版式卫星徽章 |
| 132px | 1.5 | ≈8.3px | E 版式圆形节点 |
| 132px（渐变底） | 1.3 | ≈7.2px | 白图标要更细 |

目标区间 **7–9px**，缩到 240px 时约 1px，细而不虚。写死 1.6 的图标放到 176px 会变成 11.7px，整片糊成色块。

> ⚠️ **sprite 必须内联**。`<use href="icons.svg#i-db">` 在 `file://` 下会被跨域拦截，图标消失且不报错。
> 页面写 `<!--SPRITE-->` 占位，跑 `iconlib.py --pack 页面.html` 只内联本页引用到的 symbol——不要整段粘 100 枚。

一个标题落到两种关系之一：**一对多**（一个核心能力，多类产出）或**链式**（几步串起来）。

## 10. 缩略可读标定

这张图最终大概率被放进网页卡片，**观看宽度只有 240px**，即 **1/7.3 缩放**。20–26px 的字缩完只剩 2.7–3.5px，不可读。因此全部尺寸按「缩到 240px 仍能读出大意」定标：

| 项 | 取值（按 240px 观看） |
|---|---|
| 主标题 | **76px** |
| 标签 / 浮标文字 | **48px / 44px** |
| 图标 | **84–190px**，视觉线宽 7–9px |
| 核心装置 | 画布 **50–55%** |
| 渐变体 | **恰好 1 个** |
| 描边 | **3–5px** |
| 连线 | **4px** |
| 内容元素数 | **图形 ≤4 + 文字 ≤4** |

两条纪律：

1. **字号下限 40px，无例外。** 更小的字在缩略图里等于噪点。
2. **每个标签必须写真实短标签（2–3 字）**，不用细灰条模拟文字。

验收：`python skill/hwcloud-scene-image/scripts/preview.py out.png --width 240`，打开缩略图判断。

## 11. 生成方式

**首选：HTML/CSS 按上述 token 渲染，导出 1760×1120 PNG。**

```bash
cp skill/hwcloud-scene-image/assets/template-d-orbit.html my-scene.html
# 改 title / 四个 tag / 四个 <use href="#i-*"> / badge

```

**不要用扩散模型画主体示意图**——图形化之后这个问题更尖锐：图越抽象，模型越容易画错。圆会画扁、箭头会画歪、2–3 字标签会变成伪文字。AI 生图只用于无文字氛围底图和封面插画。

**自检清单**

- [ ] 1760×1120，四边留白 ≥8%
- [ ] 只有两层壳（白卡 + 面板），**没有内容白卡**
- [ ] 色相只在 200°–250°，无绿/橙/黄混入
- [ ] 恰好 1 个渐变体，是视觉重心
- [ ] 图形占比 50–55%，不空不挤
- [ ] 图标 ≥84px，视觉线宽 7–9px
- [ ] 文字 ≤4 处，每处 2–3 字
- [ ] 边界靠投影分离，不用描边
- [ ] 无透视 / 3D / 等距 / 照片元素
- [ ] 无人物、无场景、无环境
- [ ] `linklint.py` 退出码 0
- [ ] 缩到 240px 仍能读出标题与标签大意

## 12. 连线规范

连线是全图唯一需要**手写绝对坐标**的部分，是唯一会"静默出错"的地方：少写一段横线，1760 原图上完全看不出来，缩到 240px 更看不见，只有被人指着问才会发现。

### 分叉必须拆成「枢纽 + 独立段」

**错误**——一条 path 中途转弯又分支，总线只覆盖到最左支线：

```html
<path d="M835 652 V690 H435 V716"/>
<path d="M835 690 V716"/>
<path d="M1235 690 V716"/>   <!-- 起点悬在空白处，无任何东西连接 -->
```

**正确**——所有交点在端点级重合：

```html
<path d="M835 652 V690"/>
<path d="M835 690 H435"/>
<path d="M835 690 H1235"/>
<path d="M435 690 V716"/>
<path d="M835 690 V716"/>
<path d="M1235 690 V716"/>
```

三条规则：

1. **一条 path 只做一件事**——要么直下，要么横穿，不在中途转弯后再分支。
2. **总线两端必须等于最左、最右支线的 x**，这三个数字在代码里必须字面相同。改一侧就同步改另一侧。
3. **支线起点 y = 总线 y**，**支线终点 y = 目标元素 top − 14**（14 是箭头高度）。

### 机器验收

```bash
python skill/hwcloud-scene-image/scripts/linklint.py scene.html
```

浏览器算出每根线的真实端点，判断它是否贴着某元素边缘（≤8px）或与另一条线相交（≤3px）。
不满足即报出坐标，退出码 1。`render.py` 会自动调用它，有断线时退出码 3。

**这一条不能靠肉眼替代**——它只在几何上存在，不在视觉上存在。
