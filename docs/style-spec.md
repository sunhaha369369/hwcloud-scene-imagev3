# 华为云场景图 · 风格规范（可执行版）

> 用途：后续只给「图片标题」时，按本文件直接生成风格一致的场景图。
> 分析样本：4 个产品线共 14 张原始场景图（`samples/` 本地保留，因版权未随仓库分发）。
> 可视化版本：`docs/style-guide.html`　·　可执行模板：`skill/hwcloud-scene-image/`

---

## 0. 一句话定性

**扁平矢量 UI 示意图**（flat vector product illustration）：卡片层叠造深度、渐变图标瓦片当主体、虚线连接表流程、骨架条代内容。**无人物、无透视、无照片质感。**

## 1. 画布

| 项 | 值 |
|---|---|
| 比例 | **11 : 7**，唯一输出尺寸 **1760×1120**（不再输出缩略衍生图） |
| 底色 | 纯白 `#FFFFFF`，无渐变、无暗角、无边框 |
| 四周留白 | ≥ 8% 宽 |
| 主体占比 | 视觉重量集中在中央 70% 区域 |

---

## 2. 构图：三层嵌套 + 破框浮标

层与层**逐层向右下偏移 8–14px**（这是全系统唯一的"深度"来源）。

| 层 | 内容 | 关键参数 |
|---|---|---|
| L0 | 画布 | `#FFFFFF` |
| L1 | 外壳白卡 | 宽 88–93%，圆角 ≈4%W，投影 `0 8 24 rgba(31,71,141,.06)` |
| L2 | 淡蓝面板 | 内缩 2.5%W，圆角 ≈3.5%W，垂直渐变 `#E6F2FF → #F9FAFF`（顶部最饱和） |
| L3 | 内容白卡 | 再内缩 2%W，纯白 + 1px `#F0F5FB` 描边 |
| L4 | 浮动标签 | 跨越 L2/L1 边界"破框"，投影 `0 12 32 rgba(31,71,141,.12)` |

**版式骨架（三选一）**

- **A 中心辐射**：中心主体（18–22%W）→ 3 条虚线向下 → 3 个 chip
- **B 左→右流程**：左输入/主体 → 水平虚线箭头 → 右侧 2–3 个结果标签
- **C 界面隐喻**：聊天窗 / 表单 / 编辑器 / 进度面板 + 右侧 1–2 个浮标

**动线纪律**：连线只允许**水平**或**向下分叉**，禁止斜向长距离穿越。

**标题位**：左上角，距面板边 4%W / 3%H；约 80% 的图有标题，无标题时用左下角灰底标签替代（如「本地部署」「会议录音识别」）。

## 3. 配色

| 角色 | 值 | 用途 |
|---|---|---|
| 面板顶 | `#E6F2FF` | L2 顶部 |
| 面板渐隐 | `#F1F7FF → #F9FAFF` | L2 垂直渐变 |
| 主蓝 | `#4A9DFC` | 图标、箭头、强调 |
| 深蓝 | `#2F7FE8` | 渐变起点/文字 |
| 渐变紫端 | `#7C6BF5` | 135° 渐变终点 |
| 浅填充 | `#D9E7FA` | 骨架条 |
| 连线 | `#C9DFFE` | 虚线 |
| 文字主 | `#191919` | 标题 / 标签 |
| 文字次 | `#5A616B` | 正文 |
| 告警 | `#F58A8A` | 唯一暖色，仅"告警/风险" |

> **实测修正**：上表 `#E6F2FF → #F9FAFF` 是对样本图的取样值；实际用 HTML 渲染时，渐变收到 `#F9FAFF` 会让面板底部发白、看起来只剩一圈边框，因此实现值取 `#E4F1FF → #E9F4FF → #F2F9FF → #F5FAFF`。以 `skill/hwcloud-scene-image/references/style-tokens.md` 为准。

**纪律**：全图色相锁死 **200°–250°**（蓝紫同族视为一色）；饱和度集中投放在 **20% 面积**内；暖色面积 ≤0.5%；图标统一蓝色单色线性，禁止多彩图标。

---

## 4. 光影 / 材质 / 视角

**光影**
- 无方向性主光源；无投影锥、无高光、无 AO、无体积光
- 仅三级层高投影：`0 4 16` / `0 8 24` / `0 12 32`，色为**深蓝 `rgba(31,71,141,…)` 而非黑**
- 渐变瓦片下缘带同色柔光晕（blur 20px，透明度 30%）

**材质**
- 全哑光：无金属、无玻璃、无反射、无纹理
- 唯一"实体感"= 渐变图标瓦片（135° 渐变 + 白色线性图标 + 柔光）
- 卡片纯色平涂 + 1px 极淡描边；骨架条高 1.2–2%W、宽 15–40%W
- 线框图标 1.5–2px 描边、圆头端点、不填充

**视角**
- **严格正交正视 0° 透视**；所有矩形轴对齐
- 无等距 3D、无倾斜、无地平线、无场景背景

---

## 5. 氛围

洁净 · 克制 · 可信 · 轻科技 —— **企业级 SaaS 技术说明书气质**。靠结构与留白建立秩序，不靠色彩特效制造情绪。讲"怎么运作"而非"多酷"。无人、无表情、无戏剧性 → 可无限复用不疲劳。

信息密度：中低，一图一件事。

## 6. 元素库（9 个零件）

1. **渐变图标瓦片** — 圆角 22–24%，尺寸 10–14%W，135° `#4A9DFC→#7C6BF5` + 白色线性图标 + 下缘柔光。**全图必须有且仅有 1 个**，作为视觉主体。
2. **浮动标签** — 白底 + 轻投影 + 左侧小图标 + 4–6 字，破框放置，1–2 个。
3. **骨架条** — 浅蓝圆角矩形，模拟文本/代码/列表。
4. **虚线连接** — 1.5–2px，dash 6/6，末端小三角箭头。
5. **同心虚线圆** — 2–3 圈极淡 `#C9DFFE`，用于"能力辐射/生态"。
6. **圆角方块节点** — 白底 + 淡描边 + 内部蓝色小图标。
7. **环形进度** — 2/3 圆环渐变描边，中心留白或放图标。
8. **括号式分叉** — 右侧一分为二用 ⌐ 形括线，替代两条独立箭头。
9. **渐变文字胶囊** — 蓝紫渐变填充 + 白字，全图 ≤1 个，只放一句 slogan。

## 7. 文字

| 层级 | 字号 | 颜色/字重 |

| 模块标题 | 2.6%W | `#191919` Medium |
| 标签 | 2.2%W | `#191919` Medium |
| 正文/对话 | 2.0%W | `#5A616B` Regular，行高 1.6 |

字体：思源黑体 / 苹方 / 微软雅黑。英文与技术名词（Easy Dataset、Namespace、Python、C++、MCP）同字号无衬线混排，不换字体不加粗。

## 9. 生成方式（重要）

**首选：HTML/CSS 按上述 token 直接渲染，再导出 1760×1120 PNG。**
现成模板与渲染脚本见 `skill/hwcloud-scene-image/`（三套布局模板 + `scripts/render.py`）。
理由：样本图文字、标签、图标位置极其精确，扩散模型会把这些文字画糊，无法"可复现"。

**次选：AI 生图**（仅用于无文字氛围图/补充插画），走 `mcp__uuapi-image__generate_image`（gpt-image-2.6），提示词见指南第 09 节。

**自检清单**
- [ ] 11:7 纯白，四边留白 ≥8%
- [ ] ≥3 层嵌套且逐层右下偏移 8–14px
- [ ] 色相只在 200°–250°，无绿/橙/黄混入
- [ ] 恰好 1 个渐变图标瓦片，面积 10–14%W
- [ ] 1–2 个浮标破框，投影明显更重
- [ ] 连线全为浅蓝虚线，只水平或向下
- [ ] 无透视 / 3D / 等距 / 渐变背景 / 照片元素
- [ ] 无人物、无场景、无环境
- [ ] 文字全黑或深灰
- [ ] 只讲一件事，密度中低

## 10. v2 缩略可读标定（2026-11 修订）

这张图最终大概率被放进网页卡片，**观看宽度只有 240px**，即 **1/7.3 缩放**。在这个尺度下，原规范里 2.0–2.2%W 的字号（约 20–26px）缩完只剩 2.7–3.5px —— 不可读。

因此 v2 按「缩到 240px 仍能读出大意」重新定标：

| 项 | v1（按 1760 观看） | v2（按 240 观看） |
|---|---|---|
| 主标题 | 60px | **76px** |
| 标签 / 节点名 | 20–26px | **48–50px** |
| 浮标文字 | 26px | **44px** |
| 渐变瓦片 | 132 | **170–200** |
| 节点 | 268×88 | **330×132** |
| 描边 | 1px | **3–5px** |
| 连线 | 2px | **4px** |
| 内容元素数 | 最多 25 | **≤ 7** |
| 节点内填充 | 2–3 条细骨架条 | **真实短标签（2–4 字）** |

两条新纪律：

1. **字号下限 40px，无例外。** 更小的字在缩略图里等于噪点。
2. **骨架条只做装饰，不承载信息。** 需要被读懂的内容一律写真实短标签。

验收方式：`python skill/hwcloud-scene-image/scripts/preview.py out.png --width 240`，打开生成的缩略图判断。

## 11. 连线规范（2026-11 修订）

连线是全图唯一需要**手写绝对坐标**的部分，是这套模板里唯一会"静默出错"的地方：
少写一段横线，1760 原图上完全看不出来，缩到 240px 更看不见，只有被人指着问才会发现。

### 分叉必须拆成「枢纽 + 独立段」

**错误**——一条 path 中途转弯又分支，总线只覆盖到最左支线：

```html
<path d="M835 652 V690 H435 V716"/>
<path d="M835 690 V716"/>
<path d="M1235 690 V716"/>   <!-- 起点悬在空白处，无任何东西连接 -->
```

**正确**——所有交点在端点级重合：

```html
<path d="M835 652 V690"/>
<path d="M835 690 H435"/>
<path d="M835 690 H1235"/>
<path d="M435 690 V716"/>
<path d="M835 690 V716"/>
<path d="M1235 690 V716"/>
```

三条规则：

1. **一条 path 只做一件事**——要么直下，要么横穿，不在中途转弯后再分支。
2. **总线两端必须等于最左、最右支线的 x**，这三个数字在代码里必须字面相同。改一侧就同步改另一侧。
3. **支线起点 y = 总线 y**，**支线终点 y = 目标元素 top − 14**（14 是箭头高度）。

### 机器验收

```bash
python skill/hwcloud-scene-image/scripts/linklint.py scene.html
```

浏览器算出每根线的真实端点，判断它是否贴着某元素边缘（≤8px）或与另一条线相交（≤3px）。
不满足即报出坐标，退出码 1。`render.py` 会自动调用它，有断线时退出码 3。

**这一条不能靠肉眼替代**——它只在几何上存在，不在视觉上存在。
